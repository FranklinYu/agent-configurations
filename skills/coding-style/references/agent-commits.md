# Agent commit guidance

This is the local supplement to the [Git trailer rules](../SKILL.md#git-trailers).

- Keep the existing trailers. Add each prescribed attribution and session entry
  once in the final trailer block. Reuse an existing entry with the same key
  and value.
- Use the full identifier from verified metadata for the current session. Add
  the session entry only with a verified identifier. If you cannot verify it,
  tell the user before creating the commit.
